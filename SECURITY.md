# Güvenlik Politikası

## Desteklenen sürüm

Güvenlik düzeltmeleri projenin en güncel sürümü için yayımlanır.

## Açık bildirme

Bir güvenlik açığı bulursanız ayrıntıları herkese açık issue olarak
paylaşmayın. GitHub deposunda **Security → Report a vulnerability** seçeneğini
kullanarak özel bildirim gönderin. Depo yayımlandıktan sonra bu özelliğin
**Settings → Security → Private vulnerability reporting** bölümünden
etkinleştirilmesi gerekir.

Bildirimde mümkünse etkilenen sürümü, yeniden üretme adımlarını, olası etkiyi
ve varsa önerilen düzeltmeyi belirtin. Gizli anahtar, kişisel veri veya gerçek
kullanıcı konuşmalarını bildirime eklemeyin.
